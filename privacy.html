Kebijakan Privasi

Kebijakan ini menjelaskan cara OAuth desktop client Pondasi Kode rclone mengakses dan memakai data pengguna Google.

1. Cakupan

Client ini adalah perkakas internal yang dioperasikan pemilik Pondasi Kode. Ia menghubungkan rclone di perangkat Windows milik pemilik dengan Google Drive milik pemilik, untuk backup, pemeriksaan keutuhan, dan pemulihan. Client tidak ditawarkan kepada umum dan tidak melayani akun pihak lain.

2. Data Google yang diakses

Client meminta scope Google Drive. Scope ini memungkinkan client melihat daftar berkas dan folder, membaca metadata dan isi berkas, mengunggah berkas backup, membandingkan hash, serta mengunduh berkas untuk pemulihan.

Scope Drive penuh dipakai karena folder backup dibuat pemilik secara manual sebelum OAuth client ini ada, sedangkan scope yang lebih sempit hanya menjangkau berkas yang dibuat client itu sendiri. Dalam pemakaian, remote rclone dipatok ke satu folder khusus Pondasi Kode, tetapi scope OAuth-nya sendiri lebih luas daripada folder itu.

3. Cara data Google dipakai

  • Menyalin berkas kerja Pondasi Kode yang dipilih ke Google Drive milik pemilik.
  • Melihat daftar berkas backup dan membandingkan ukuran, waktu, serta checksum-nya.
  • Mengunduh berkas yang dipilih saat pemilik melakukan pemulihan.
  • Menelusuri penyebab kegagalan backup yang dijalankan pemilik.

Data pengguna Google tidak dipakai untuk iklan, pembuatan profil, pelatihan model, keputusan kredit, pengawasan, atau tujuan lain di luar fungsi tersebut.

4. Penyimpanan dan keamanan

Berkas backup tetap berada di Google Drive milik pemilik. Access token dan refresh token OAuth disimpan secara lokal di konfigurasi rclone milik pemilik dan dikecualikan dari source control. Situs publik ini tidak menerima dan tidak menyimpan token OAuth, isi berkas Drive, maupun kredensial akun.

5. Pembagian dan transfer

Data pengguna Google tidak dijual, tidak disewakan, tidak dibagikan kepada pengiklan, dan tidak ditransfer kepada pihak ketiga yang tidak berkaitan. Data hanya diproses oleh Google Drive dan oleh client rclone yang dijalankan secara lokal, sejauh diperlukan untuk backup atau pemulihan yang diminta pemilik.

6. Retensi dan penghapusan

Pemilik mengendalikan masa simpan dan penghapusan berkas backup di Google Drive. Kredensial OAuth lokal dapat dihapus dengan menghapus konfigurasi remote rclone. Akses juga dapat dicabut kapan saja lewat pengaturan keamanan Akun Google. Pencabutan akses menghentikan panggilan API berikutnya, tetapi tidak dengan sendirinya menghapus berkas yang sudah tersimpan di Drive.

7. Kendali pengguna

Pemilik dapat memeriksa, mengunduh, memindahkan, atau menghapus berkas backup langsung di Google Drive; menghentikan proses backup; mencabut izin OAuth; mengganti OAuth client; atau menghentikan seluruh integrasi.

8. Penggunaan Terbatas

Pemakaian informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

9. Data hosting situs

Situs kebijakan ini di-host di GitHub Pages. Situs tidak memakai analytics, pelacak iklan, cookie, formulir, ataupun JavaScript. GitHub dapat memproses informasi pengunjung seperti alamat IP untuk keamanan dan pengoperasian layanannya, menurut GitHub Privacy Statement.

10. Perubahan dan kontak

Kebijakan ini diperbarui sebelum terjadi perubahan material pada akses atau pemakaian data Google oleh aplikasi. Pertanyaan yang tidak bersifat sensitif dapat dikirim lewat issue tracker publik milik repository situs ini. Jangan mengirim kredensial, token, data pribadi, atau informasi keamanan yang sensitif lewat issue publik.
